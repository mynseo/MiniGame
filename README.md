# 민서민서김

브라우저에서 바로 하는 미니 게임 모음입니다. 설치·빌드 없이 HTML 파일 하나씩으로 돌아갑니다.

**바로 하기: https://mynseo.github.io/MiniGame/**

## 게임

### 🛗 닫힘 버튼 연타 — [`elevator/`](elevator/)

3D 엘리베이터 안, 나 혼자. 복도 끝에서 누가 뛰어옵니다. 오기 전에 닫힘 버튼을 연타해 문을 닫으세요.
늦으면 문 사이로 손이 쑥 들어오고, 같이 타게 됩니다.

- **1. 고정 버튼**: 문 옆 조작반의 닫힘 버튼. 30번을 6초 안에 최대한 빠르게.
- **2. 랜덤 버튼**: 누를 때마다 열림·닫힘 버튼이 서로 자리를 바꿀 수도 있습니다. 20번을 7초 안에. 열림을 잘못 누르면 문이 다시 열립니다.

닫힘을 누를 때마다 화면이 번쩍이고 숫자가 튀어나오며, 문이 닫힐수록 효과가 커집니다.
모바일에서는 열림·닫힘 버튼이 화면 맨 아래에 크게 나옵니다.

### 🚌 급정거 버스 3D — [`bus-3d/`](bus-3d/)

손잡이를 놓친 채 급정거·급출발하는 버스에서 두 발로 버티기. 폰을 기울이거나(← → 키, 화면 좌우 꾹 누르기) 쏠리는 반대쪽으로 버팁니다.
신호등·정류장·과속방지턱이 미리 보이고, 고양이는 예고 없이 뛰어듭니다. 바닥에는 캔과 귤이 데굴데굴 굴러다닙니다.
마을 → 간선 → 광역 → 심야버스로 갈수록 기사님이 거칠어집니다.

최고 기록은 모두 브라우저에 저장되고, 첫 화면 카드에 표시됩니다.

## 3D 모델 규칙

모든 게임의 사람·동물은 [`shared/minseo3d.js`](shared/minseo3d.js)의 기본 도형 캐릭터로 만듭니다 (DrumSimulator 드러머와 같은 생김새).

- 큰 공 머리 + 바가지 머리카락 + 작은 점 눈. 코·입은 없고, 놀랄 때만 동그란 입이 열립니다.
- 몸통·팔다리는 캡슐, 신발은 둥근 캡슐. 무광 재질에 부드러운 그림자, 영화 같은 톤(ACES).
- 정해 둔 동네 사람 색 조합(`MS3D.LOOKS`): `me`, `drummer`, `office`, `student`, `granny`, `driver`, `runner`, `cat`.

```js
const p = MS3D.person(MS3D.LOOKS.office);   // 서 있는 사람 (얼굴 +Z, 원점은 발밑)
p.arm('R', 2.9, 0.1, 0.1);                   // 손잡이 잡기: 팔을 위로
p.run(phase);                                // 뛰기 한 프레임
p.panic(true);                               // 놀란 얼굴
p.update(time);                              // 눈 깜빡임
MS3D.person({ ...MS3D.LOOKS.granny, sit: true }); // 앉은 사람
```

## 새 게임 추가하기

1. `<게임-id>/index.html` 에 게임을 넣습니다 (예: `ramen-water/index.html`).
2. 게임 안에 목록으로 돌아가는 링크를 넣습니다: `<a href="../index.html">← 게임 목록</a>`
3. 썸네일을 `thumbs/<게임-id>.jpg` 로 저장합니다 (16:10, 800×500 권장).
4. `games.js` 에 한 칸을 추가합니다. 첫 화면 카드는 이 목록을 보고 자동으로 그려지고, 가장 최근 `added` 날짜의 게임에 NEW 표시가 붙습니다.

```js
{
  id: 'ramen-water',
  title: '라면 물 맞추기',
  desc: '한 줄 소개',
  controls: ['터치', '키보드'],
  color: '#ff9a2e',
  added: '2026-11-05',
  best: { key: 'ramen-water-best', unit: 'ml' }   // 게임이 localStorage에 저장하는 최고 기록 키 (선택)
},
```

## 로컬에서 하기

파일을 브라우저로 바로 열거나, 폴더에서 정적 서버를 띄우면 됩니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.
(처음 한 번은 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꿔 주세요.)

버스 게임의 폰 기울기 조작은 HTTPS 주소(GitHub Pages)에서 작동합니다. 아이폰은 시작할 때 센서 사용 허락을 묻습니다.
급정거 버스 3D는 three.js를 cdnjs에서 불러오므로 인터넷 연결이 필요합니다.
